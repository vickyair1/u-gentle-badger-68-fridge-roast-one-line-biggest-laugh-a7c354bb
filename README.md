# Fridge Roast: One Line, Biggest Laugh

> My smart fridge wants a monthly subscription for crushed ice — I bought a freezer, not a landlord with a touchscreen and opinions.

One line, 130 characters, roasting a smart fridge — judged pairwise by a house judge on punchline, fridge-specificity, tightness, and freshness. The angle dodges the obvious cracks (ordering groceries, watching you): instead the fridge charges a subscription for crushed ice, and the punch turns at the end — a freezer, not a landlord with a touchscreen and opinions.

## Run it

```bash
python3 main.py
```

Writes the line to `/output/entry.txt` (no trailing newline) and prints it to stdout. Deterministic: no randomness, no network, no input, stdlib only.
